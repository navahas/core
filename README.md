# QUBIC Trust-Lease 
## - Decentralized Scoring For Secure Leasing

- Team: 8 - Dream Team 

This project is powered by a Qubic Node core, with a custom smart contract (TrustScore) designed to track and increment reputation values. The backend (hm25-backend/) acts as a lightweight wrapper around the qubic-cli, simplifying interactions like minting assets, querying scores, and managing state. The frontend (hm25-frontend/) provides users a clean UI to interact with these smart contract features.

The TrustScore system can integrate certification downloads via Vottun, and is designed to leverage Qubic’s epoch-based scheduling to automate tasks like rent checks, contract cancellations, and periodic score updates.
